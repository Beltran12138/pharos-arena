» How do I check how much USDC the address 0x18573fa18fd17ddfd790b4a5b5b2977aad3b4efb holds on Pharos mainnet?

1. PLAN (Docs MCP)
  The docs answer:
    Use this read-only `cast` call:
    
    ```bash
    cast call 0xc879c018db60520f4355c26ed1a6d572cdac1815 \
      "balanceOf(address)(uint256)" \
      0x18573fa18fd17ddfd790b4a5b5b2977aad3b4efb \
      --rpc-url https://rpc.pharos.xyz
    ```
    
    The result is the raw integer balance in token base units. The [Token Registry](/getting-started/token-registry) lists USDC at `0xc879c018db60520f4355c26ed1a6d572cdac1815`. The [Pacific Mainnet](/getting-started/network/pacific-mainnet) documents the RPC endpoint.
    
    **Documentation gap:** The mainnet token registry does not specify USDC decimals, and the docs do not state this address’s current balance. The [x402 Pacific Mainnet](/developer-guide/x402/x402-pacific-mainnet) uses six-decimal precision for USDC; using that convention, divide the returned integer by `1,000,000` to get USDC.
