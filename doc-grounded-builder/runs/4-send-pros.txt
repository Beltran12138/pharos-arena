1. PLAN (Docs MCP)
  The docs answer:
    For **native PROS**, send `0.01` with this Cast command:
    
    ```bash
    cast send 0x6649228a90bef932a1aa98e5c4412dadba8a04c5 \
      --value 0.01ether \
      --private-key "$PRIVATE_KEY" \
      --rpc-url https://rpc.pharos.xyz
    ```
    
    Set `PRIVATE_KEY` in your shell first. The command sends **0.01 PROS** (`10^16` wei) and requires additional PROS for gas. Pharos Pacific Mainnet uses chain ID `1672` and RPC `https://rpc.pharos.xyz` ([Pacific Mainnet](/getting-started/network/pacific-mainnet)).
    
    **Contract address:** Native PROS has no token contract address for this transfer. The registry lists `0x52c48d4213107b20bc583832b0d951fb9ca8f0b0` as **WPROS**, the wrapped token—not native PROS ([Token Registry](/getting-started/token-registry)).
    
    **What the docs don’t document:** They don’t provide a dedicated, exact native-PROS transfer command. They provide a generic native-token `cast send` example; the command above applies that pattern to the mainnet RPC and PROS amount ([Pharos Skill Engine](/tooling-and-infrastructure/pharos-skill-engine-guide)).
