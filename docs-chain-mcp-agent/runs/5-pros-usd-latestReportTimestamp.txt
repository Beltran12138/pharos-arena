## 1. What the docs say about latestReportTimestamp on Chainlink PROS/USD price feed proxy

  `latestReportTimestamp()` reads the observation time for the latest PROS/USD report. It is a timestamp, not a price value; the feed’s price uses 18 decimals.
  
  * **Parameters:** None are documented for this getter.
  * **Meaning:** The timestamp records when the Chainlink DON observed the price, not when its update transaction landed on Pharos. The docs say `startedAt` and `updatedAt` both represent this same observation time.
  * **Units:** Use it as a time value and compare it with the current block timestamp when checking freshness. The docs do not explicitly state the getter’s ABI return type or timestamp unit.
  
  The [Chainlink Push Engine Feeds](/tooling-and-infrastructure/oracles/chainlink-pe) lists this proxy as the Pacific Mainnet PROS/USD feed and recommends enforcing an application-specific staleness limit.

  Sources: Chainlink Push Engine Feeds <https://docs.pharos.xyz/tooling-and-infrastructure/oracles/chainlink-pe>; Chainlink Data Feeds <https://docs.pharos.xyz/tooling-and-infrastructure/oracles/chainlink-ds>; Get PROS Gas <https://docs.pharos.xyz/getting-started/get-pros-gas>
