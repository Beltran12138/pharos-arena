$ pharos-docs "how do I use Chainlink price feeds on Pharos?"
For normal on-chain reads, call the **price-pair proxy** for your network. For example, the Pacific Mainnet `ETH/USD` proxy is `0x1Ed3e8CdC173363593BfAD9bF77aa2A0e7351DB8`. The feeds use **18 decimals**, so divide the answer by `1e18` to display the price.

    function latestAnswer() external view returns (int256);
    function latestTimestamp() external view returns (uint256);
}
