$ pharos-docs "how do I deploy a contract?"
For Pharos, a quick Foundry deployment looks like this:

1. Install Foundry, set up your contract, and compile and test it:

   ```sh
   forge build
   forge test
   ```
2. Create a deployment script that loads `PRIVATE_KEY`, starts broadcasting, and deploys your contract. The [Write Your First Token](/developer-guide/foundry/write-your-first-token) includes a sample script.
3. Set your deployer key and broadcast to your network’s RPC:

   ```sh
   export PRIVATE_KEY=<your-private-key>
   forge script script/DeployToken.s.sol --rpc-url <PHAROS_RPC_URL> --broadcast
   ```
  … (--full for the rest)
